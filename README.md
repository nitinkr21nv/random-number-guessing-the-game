# Random Number Guessing Game

A simple Random Number Guessing Game built using HTML and JavaScript.
In this game, the user selects a range, the computer generates a random number within that range, and the user has to guess the correct number with hints.

# Features
- User can select the range (maximum number).
- Random number is generated automatically.
- Hints are provided after each guess (Too High / Too Low).
- User can type "quit" to exit the game anytime.
- Beginner-friendly JavaScript project.

# Technologies Used
- HTML
- JavaScript


# How to Run the Project
1. Clone the repository:
   git clone https://github.com/nitinkr21nv/random-number-guessing-the-game.git
2. Open the project folder.
3. Open index.html in your browser.
4. Start playing the game.
